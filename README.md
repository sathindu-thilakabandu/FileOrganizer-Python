# File Organizer Bot 🤖

A Python-based automation tool that cleans up cluttered directories by sorting files into categorized folders based on their extensions.

## 🚀 Features
* **Automatic Sorting:** Detects file types and moves them to Images, Videos, Documents, etc.
* **Smart Folder Creation:** Automatically creates destination folders if they don't exist.
* **Safe Handling:** Skips existing directories to avoid recursive loops.
